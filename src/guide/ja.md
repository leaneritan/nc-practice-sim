# NC Practice Simulator — 使い方ガイド

## 1. はじめに

1. プログラムの読み方、Mazatrol風のユニット入力、簡易操作盤、加工結果の確認を練習するアプリです。**練習用シミュレーター — 実機の操作は必ず会社の指導に従うこと。** Mazakの公式制御装置でもCAMでもなく、実機への接続や実機の安全確認はできません。Matrix／Smoothなどで画面・仕様は異なります。
2. 下の図で4つの領域を確認します。下部の画面キーは表示内容を、モードキーは機械への指令方法を切り替えます。
3. ヘッダーの**日本語／English**で言語を切り替えます。ガイドも同じ章のまま切り替わります。[ワーク座標系](term:workCoordinate)など下線付き用語にマウスを重ねる、フォーカスする、またはタップすると読み方・意味が出ます。Escapeで閉じます。用語集はシミュレーターの下にあります。
4. 新しい練習は、運転中なら停止・RESETしてから、操作盤の下の**段取りを初期値に戻す**を押します。G54〜G59、工具、ポケット幅を初期化し、仮想機械を原点へ戻し、工具を外して素材を交換します。プログラムと言語は残ります。
5. **使い方ガイド**はこの章、各画面の**?**は対応する章を開きます。ガイドを開くとFEED HOLDがかかり、ジョグ入力も止まります。**シミュレーターに戻る**で戻り、必要ならCYCLE STARTで再開します。プログラム・段取り・言語はこのブラウザーに保存されますが、機械位置・除去形状は再読込みで初期化されます。

```text
[1] ヘッダー：タイトル／使い方ガイド／日本語・English
[2] 表示部：状態表示＋選択画面
    POSITION／PROGRAM／SHAPE CHECK
    TOOL DATA／WORK OFFSET／ALARM
[3] 操作盤：モードキー／CYCLE STARTなど
[4] 下部：段取り初期化／素材交換／用語集
```

**3種類のリセット：** RESETは実行・アラームを解除しますが、軸位置と除去済み素材は戻しません。「素材を交換」は下穴履歴も含め新品にし、位置・段取りを保持します。「段取りを初期値に戻す」は段取りと原点位置も戻します。これらはシミュレーターの機能であり、実機の復旧手順ではありません。

## 2. 機械の基礎

1. 段取り初期化後にPOSITIONを開きます。[機械座標系](term:machineCoordinate)は機械固有の原点、[ワーク座標系](term:workCoordinate)は加工物の原点が基準です。原点位置・Hなしでは、機械XYZが`(0, 0, 0)`でもワークXYZは`(500, 250, 400)`です。
2. WORK OFFSETで[G54](term:workOffset)の**X−500、Y−250、Z−400 mm**を確認します。素材上面の左下角を機械空間のその位置に置きます。素材は+X/+Y方向に広がり、ワークZは−20〜0です。G55〜G59は別の座標枠で、このアプリの初期値は同じです。
3. [工具長補正](term:toolLength)を確認します。Tは工具選択、M06は装着、G43 Hは長さの補正番号です。T1は径6エンドミルで、H1＝**120 mm**です。Hは工具長であり、ワークオフセットではありません。G49は補正を解除しますが、実際の工具が短くなるわけではありません。
4. 数値だけを確かめる練習：段取り初期化後、MDIで`T1 M06`を入力してCYCLE START。完了後、`G54 G00 G43 H1 X10. Y15. Z5.`を入力して再度実行します。POSITIONはワーク`(10, 15, 5)`、機械`(−490, −235, −275)`になります。正しいHを使うと、ワークZが工具先端の高さに対応します。
5. 下図を読みます。機械Z0はストローク上端なので、通常の加工位置の機械Zは負です。負だから素材の中とは限りません。ワークZ5は素材上面の5 mm上です。機械の基準点、工具先端、テーブルは別の位置です。

```text
機械Z                         T1／H1＝120の例
   0  ─ 原点・ストローク上端
−275  ─ 機械の基準点          ┐
                             │ 工具長120 mm
−395  ─ 工具先端              ┘ ワークZ＋5
−400  ─ 素材上面・G54 Z         ワークZ 0
−420  ─ 素材底面                ワークZ−20
−460  ─ テーブル・Z下限

機械X＝G54 X＋ワークX       −500＋10＝−490
機械Y＝G54 Y＋ワークY       −250＋15＝−235
機械Z＝G54 Z＋ワークZ＋H    −400＋5＋120＝−275
```

| 初期工具 | 工具長／H（mm） |
| --- | --- |
| T1 END MILL | 120 |
| T2 DRILL | 160 |
| T3 TAP | 150 |
| T4 FACE MILL | 100 |
| T5 BALL END MILL | 130 |
| T6 90° SPOT / CENTER DRILL | 110 |
| T7 REAMER | 180 |
| T8 CHAMFER CUTTER | 110 |

ストロークは機械X −1020〜0、Y −510〜0、Z −460〜0 mmです。ワーク表示が自然に見えても、Hが間違っていれば実際の工具形状は干渉します。

## 3. 操作盤

1. 表で用途を確認してモードを選びます。画面の切替とモードの切替は別です。運転中・一時停止中はモード変更と段取り編集がロックされます。実行を取り消す場合はRESETを使います。
2. 原点付近で**HANDLE**を練習します。倍率×100で**Y−**を3回クリックします。1回は0.001×100＝0.100 mmなので、機械Yは−0.300になります。Y+で0へ戻れます。原点より正方向へ進めるとアラームです。RESETではYは0へ戻りません。原点へ戻す機能はZERO RETURNです。
3. 保存したプログラムはMEMORY→CYCLE STARTで実行します。FEED HOLDで一時停止、CYCLE STARTで再開、RESETで実行を取り消します。操作前に下のボタン・倍率表を確認してください。

| モードキー | 動作・用途 |
| --- | --- |
| EDIT | プログラムの作成・選択とテキスト／ユニットの編集。実行はしません。 |
| MEMORY | 選択した保存済みプログラムをCYCLE STARTで実行。 |
| MDI | 一時的なGコードを入力して実行。現在位置・モーダル状態から続けます。 |
| JOG | 軸キーを押している間、300 mm/min×送り倍率で移動。手動位置決め練習用。 |
| HANDLE | 1クリックで0.001 mm×1／×10／×100の1パルス移動。微調整用。 |
| RAPID | 軸キーを押している間、6000 mm/min×早送り倍率で移動。進路が空いている場合に使います。 |
| ZERO RETURN | 軸キーをクリックするとその軸が機械原点へ直線的に戻ります。干渉しない経路を自動選択しません。 |
| TAPE | 無効。テープ／DNC入力は再現していません。 |

```text
EDIT → 選択 → MEMORY → CYCLE START → 運転
                         FEED HOLD ↓ ↑ CYCLE START
                                  一時停止
RESET → 実行解除（軸位置・除去済み素材は保持）
```

| ボタン・設定 | 動作・用途 |
| --- | --- |
| CYCLE START | MEMORY／MDIの開始、一時停止・プログラム停止の再開、次の1ブロックの実行。 |
| FEED HOLD | 移動・ドウェル・工具交換の途中で停止し、続きから再開できる状態を保持。 |
| RESET | 実行・アラームを解除し、仮想主軸・クーラントを停止。位置・素材は保持。原因を修正してから再開。 |
| SINGLE BLOCK | 入力1ブロックごとに停止。穴あけでは全切込み・退避が1ブロック。Mazatrolもユニット単位でなく生成ブロック単位です。 |
| DRY RUN | 通常の切削送りを1000 mm/min×送り倍率に変更。このアプリでは除去・干渉判定が続き、空運転への切替ではありません。 |
| OPTIONAL STOP | M01による停止を有効化。M00は常に停止。CYCLE STARTで再開します。 |
| COOLANT | 仮想クーラントを切替。後のM08／M09で再びプログラム指令に従います。実際の液体・切削力は再現しません。 |
| 送りオーバーライド | 通常の指令送りの0〜150%。0は切削送りを止めますが早送りは止まりません。 |
| 早送りオーバーライド | 6000 mm/minの25／50／100%。 |
| 主軸オーバーライド | 指令回転数の50〜120%。G84の送りもこの倍率に追従しF/Sピッチを保持。送り倍率とDRY RUNはタップ送りを変更しません。 |

入力欄・ボタン以外にフォーカスがあるとき、JOG／RAPID／HANDLEでは矢印キーがX/Y、Page Up/DownがZです。JOG／RAPIDは押し続け、HANDLEはキー押下1回につき1パルスです。ガイド中は無効になります。[早送り](term:rapid)と[切削送り](term:feed)は別の移動です。

## 4. 段取り

1. 練習は初期段取りから始めます。[素材](term:stock)は100×60×20 mm、上面ワークZ0です。[バイス](term:vise)の口金はY0／Y60の外側でZ−5より下、テーブルは機械Z−460です。素材寸法と保持具は固定の模式形状で、実機認証済みの形状や編集可能な治具ではありません。
2. TOOL DATAでポケット番号、種類、公称径、実径、長さを確認します。実径が除去・干渉に使われ、H1〜H20には各行の長さを使います。有効値はEnterまたはフォーカスを外すと保存。寿命は保存のみで消費しません。ポケット幅0は追加のEIA径チェックを無効にし、設定する場合は素材幅でなく加工するポケット幅を入れます。
3. WORK OFFSETで使用するG54〜G59、XYZ値、符号を原点の意図と照合します。G54変更は仮想素材・バイスの配置も変え、G55〜G59は別のプログラム座標枠です。選択色だけで正しいと判断せず数値を確認します。
4. CYCLE START前に下表を確認します。Tだけでは次工具の選択で、装着はM06です。M06は機械Z0・主軸停止・固定サイクル解除が必要で、交換は仮想2秒。その後に正しいG43 Hを適用します。数値は[機械の基礎](#basics)を参照してください。

```text
XY上面：Y0〜60、X0〜100に素材
        左下上面がG54ワーク原点
XZ側面： Z  0 ─ 素材上面
         Z −5 ─ 口金上面
         Z−20 ─ 素材底面
         Z−30付近より下 ─ バイス台
```

| 段取りチェック | 確認内容 |
| --- | --- |
| プログラム・材質 | 正しいプログラム／形式、mm単位、材質、加工順序か。 |
| ワーク原点 | G54〜G59、符号、素材配置は正しいか。Mazatrol WPCはG54基準。 |
| 工具 | T・種類・実径は正しいか。Hは実際の工具長と一致するか。 |
| 保持・退避 | 素材・バイス、進入・退避・工具交換の進路を理解したか。 |
| 深さ・下穴 | 素材底面より上か。止まりタップ／リーマより下穴が深いか。スポット径に工具が足りるか。 |
| 切削条件 | 主軸方向・回転数、送り、クーラント、ポケット進入、倍率は適切か。 |
| 最初の確認 | SHAPE CHECKを確認し、必要なSINGLE BLOCKを選んだか。 |

段取り編集は運転・一時停止中にロックされます。「素材を交換」は軸を動かさず材料・下穴履歴を初期化。「段取りを初期値に戻す」は段取りと原点位置も初期化します。

## 5. Gコードを書く

1. 段取り初期化後、EDIT→PROGRAM→プログラム一覧・新規作成で**EIA/ISO (G-code)**を作成し、下の例を貼り付けます。(20,20)、(80,20)に径6.8、元の素材上面から深さ8 mmの穴をあけます。回転数・送りはシミュレーター練習用の値です。
2. 各行のコメントを読みます。安全開始ブロックで[絶対値指令](term:absolute)、mm、XY平面、毎分送りを明示し、工具交換前に旧サイクルを解除します。[G28](term:machineCoordinate)は中間点経由です。`G91 G28 Z0.`は増分0の中間移動後にZ原点へ戻ります。その後G90に戻します。
3. [モーダル](term:modal)の固定サイクルを確認します。最初の穴でG81を宣言、次はXYだけ、最後に**G80**です。G83は切込みQ、G82は整数ミリ秒の停止P、G84はM03/Sとピッチに合うFでタップ加工。G81の一連の動作はSINGLE BLOCKでは1ブロックです。
4. 小数点を確認します。**X10.＝10 mm**。**X10**には黄色警告が出ます。実機では設定により**0.010 mm**と解釈するものが多いためです。このアプリの通常モードは10 mm、**厳密な小数点入力**を有効にすると小数点なしのX/Y/Z/I/J/R/Qを0.001 mm単位にします。F/S/P/T/H/Dは変えません。距離には小数点を明記してください。
5. MEMORY→CYCLE STARTの前にSHAPE CHECK→実行を確認します。この例はアラームなしで終了し、機械Z0へ戻るはずです。コードを貼り付ける先はこのシミュレーターに限ります。

```text
安全開始 → Z原点 → T／M06 → G43 H → 主軸・クーラント
        → 固定サイクル＋XY繰返し → G80 → 退避 → Z原点 → M30
```

```gcode
O6001 (2穴の練習 - シミュレーター専用)
G21 G17 G90 G94 G40 G80 (mm・XY・絶対値・毎分送り・サイクル解除)
M05 M09 (主軸とクーラントを停止)
G91 G28 Z0. (中間点への増分移動0の後にZ原点へ戻す)
G90 G49 G54 (絶対値へ復帰・古いHを解除・G54選択)
T2 M06 (機械Z0で標準の径6.8ドリルを装着)
G00 G43 H2 Z15. (長さ160のH2を適用し先端を上面の15 mm上へ)
S1800 M03 (主軸を時計回り1800回転で起動)
M08 (クーラントON)
G98 G81 X20. Y20. Z-8. R3. F120 (1穴目を加工し開始高さZ15へ戻る)
X80. Y20. (有効なG81条件を使い2穴目を加工)
G80 (穴あけサイクル解除)
G00 Z15. (退避高さへ)
M09 M05 (クーラントと主軸を停止)
G91 G28 Z0. (増分0の中間点経由でZ原点へ戻す)
G90 (絶対値入力に戻す)
M30 (プログラム終了)
```

対応範囲はG00〜G03、G17/G21/G40/G94、G43/G49、G54〜G59、G28、G80〜G84、G90/G91、G98/G99および実装済みMコードです。G41/G42など未対応コードはアラームです。実機の全仕様を使えると考えないでください。[R点](term:retractPlane)は穴あけの接近高さ、[イニシャル点](term:initialPlane)はG98で戻る開始高さです。

## 6. Mazatrol

1. 段取り初期化後、EDIT→PROGRAM→一覧で**Mazatrol**を作成するか、**Mazatrolサンプルを読み込む**を押します。元のEIAも一覧に残り、各プログラムは別々に保存されます。
2. ユニットボタンを選び項目を入力します。[COMMON](term:commonUnit)は材質と初期／退避Z、[WPC](term:wpcUnit)はG54からの移動・回転です。まずA5052、初期Z15、WPC XYZ/θ＝0にします。WPCはWORK OFFSETを書き換えません。[END](term:endUnit)は主軸・クーラント停止、Z原点復帰で終了します。
3. ENDの前に加工ユニットを追加します。点加工はDRILLING、[RGH CBOR](term:counterbore)、[TAPPING](term:tapping)、[REAMING](term:reaming)。面加工は[FACE MILL](term:facing)、[POCKET](term:pocket)。[LINE OUT](term:outsideContour)は閉じた凸輪郭で、LINE終点とARC終点／中心／方向を入力し、円弧接続は接線でつなぎます。
4. 下表の形状行を追加します。パターンに置換する場合は最初のPT行を削除してください。残すと余分な1穴になります。サンプルのM8×4穴はSQR X15/Y15、幅70／高さ30です。
5. 材質・寸法変更後に[工具を自動展開](term:autoTools)します。工具行は編集可能で、再展開すると手動上書きを置換します。T/H・種類・径をTOOL DATAと一致させます。T0は工具未一致です。[切削速度](term:cuttingSpeed)C-SPはm/min、[送り](term:feed)FRはmm/min。これらは練習用初期値で、実加工で検証済みの条件ではありません。
6. 実行前にSHAPE CHECK、比較には**Gコードで表示**を開きます。両形式は移動・素材・アラームを共用します。生成コードは学習用で、実機Mazatrolの版ごとの差異を再現するものではありません。

```text
COMMON → WPC → FACE MILL → TAPPING → POCKET → END
                  各ユニット＝形状＋工具順序
                             ↓
                    等価EIA → 共通シミュレーション
```

| 形状行 | 入力・結果 |
| --- | --- |
| [PT](term:pointPattern) | 単独のX/Y点。 |
| [LIN](term:linePattern) | 始点X/Y、個数、X/Y間隔。始点を含む直線配列。 |
| [SQR](term:rectanglePattern) | X/Y、幅／高さ。長方形の4隅。 |
| [GRD](term:gridPattern) | X/Y、各軸の個数と間隔。格子配列。 |
| [CIR](term:circlePattern) | 中心X/Y、半径、個数、開始角。円周上の等配。 |
| [LINE](term:lineShape)／[ARC](term:arcShape) | LINE OUT輪郭の終点。ARCは絶対中心X/Yと時計／反時計回りも指定。 |

**サンプルの確認値：** 上面Z0を1 mm削ると新上面はZ−1。M8×1.25の深さ10は先端Z−11です。90°[スポットドリル](term:spotDrill)は標準T6径10を使い、深さ4.25でスポット径8.5。T2径6.8の下穴深さは14.44でねじより深くします。止まりタップ／リーマの下穴深さ＝仕上げ深さ＋0.3×仕上げ径＋0.3×ドリル径。深さ20以上の貫通形状には追加しません。総深さは編集可能で、止まり仕上げが下穴以上に深いとアラームです。古い段取りは初期化後にサンプルを再読込みしてください。

サンプルの[ポケット](term:pocket)はX30/Y20、40×20、上面Z−1、深さ4で底Z−5。[ポケット進入](term:pocketEntry)は最大3°の往復ランプが初期値、突込みを選ぶとZ送り30%です。内隅には工具半径が残ります。一般的な凹輪郭補正やねじ山形状は再現しません。

## 7. 運転と確認

1. SHAPE CHECKで実行前のMazatrol形状を見ます。「実行」は現在の素材・段取り・位置のコピーで即時計算し、操作盤の機械を動かしません。実行済み／停止中の経路がある場合はその表示になり、RESETで実行を解除すると新しく確認できます。除去済み素材はRESETで戻りません。
2. XY上面・XZ側面を[ワーク座標](term:workCoordinate)で読みます。破線は早送り、実線は切削送り、マーカーは現在の終点です。各移動は当時の座標枠を保持し、POSITIONには機械座標と残移動量を別に表示します。
3. 3Dはドラッグで回転、スクロールで拡大縮小、右ドラッグで平行移動、「視点を戻す」でカメラ初期化。1 mm高さマップとサンプリング工具形状による近似で、ねじ・アンダーカット・ホルダー干渉の安全保証はできません。WebGLがなくてもコア計算と2D確認は動きます。
4. MEMORYでSINGLE BLOCKを有効にし、CYCLE STARTで1ブロックずつ進めます。行／ユニット番号と予想位置を確認します。固定サイクル1ブロックには全切込み・退避を含みます。FEED HOLDは途中停止、RESETは実行解除。新品素材からやり直す練習では「素材を交換」してください。
5. [アラーム](term:alarm)ではALARM画面で元の行（N番号ではない）、詳細、Mazatrolユニットを読みます。行0は設定／ユニット検証です。RESETで停止を解除し、EDITや段取り画面で原因を直してからSHAPE CHECKをやり直します。RESETだけで切削跡や工具位置が安全な状態に戻るわけではありません。

```text
形状 → 即時確認 → 経路・素材を読む → 1ブロックずつ運転
                      アラーム ↓
       行と原因を読む → RESET → 修正 → 再確認
```

## 8. 実機での安全習慣

1. これは指導付き訓練のための一般知識です。**練習用シミュレーター — 実機の操作は必ず会社の指導に従うこと。** 適用する手順と制御装置の版を指導者に確認してください。シミュレーション成功は、実機で運転してよいという許可や安全の証明ではありません。
2. 初回運転前に、会社で承認された段取り手順でプログラム／版、単位、保持、工具番号、実際の工具長、G54〜G59、退避量を確認します。符号・測定・補正値に迷ったら経験者に照合してもらいます。
3. 指導者の手順に従って初回はSINGLE BLOCKを使い、開始前に残移動量と方向を確認します。送り倍率はその加工で認められた低い割合にし、早送り倍率も別に確認します。タップなど同期加工では倍率の扱いが異なる場合があります。
4. 初回は動きを観察し、FEED HOLDの近くに手を置きます。実機のFEED HOLD・RESET・非常停止の挙動を指導者から学んでください。FEED HOLDは非常停止ではなく、主軸・クーラントが止まるとは限りません。危険が生じたら訓練された非常時の手順に従います。
5. ガード・インターロックを使用し、動く工具と切りくずから離れます。軸や主軸が動く可能性がある状態で手を入れる、測定する、切りくずを取る、保持を変更することはしません。予想外の結果や音では止めて相談し、復旧経路を推測したり保護機能を無効にしたりしないでください。

```text
指導者の承認した段取り確認
          ↓
原点・工具・保持・退避量を照合
          ↓
指導下の初回運転：SINGLE BLOCK＋適切な倍率
          ↓
観察 → 必要なら停止／訓練された非常対応 → 相談
```

シミュレーターのZERO RETURN・RESET・段取り初期化は、実機の原点復帰／復旧手順を教えるものではありません。自動採点レッスン、会社固有の訓練、Matrix／Smooth完全互換はこのガイドの範囲外です。
